
# Nombre del Proyecto: Shara

## Descripción del Proyecto
Sara es una aplicación web de comercio electrónico de moda, diseñada para la gestión y venta de ropa y accesorios. La plataforma permite a los usuarios navegar por un catálogo de prendas organizado por colecciones, gestionar su perfil de cliente y realizar pedidos.

## Propuesta Preliminar de Historias de Usuario

A continuación se detallan las funcionalidades clave para esta primera fase, asignadas preliminarmente a los miembros del equipo:

1.  **Exploración del Catálogo**
    * Los usuarios que visiten la página web podrán ver un listado de los productos clasificado por categorías 
   

2.  **Gestión de Productos**
    * Los administradores podrán modificar el stock, las características y precios de los productos cuando crean conveniente.
   

3.  **Registro e Inicio de Sesión**
    * Los usuarios podrán registrarse con nombre, usuario y contraseña para tener una cuenta.
   

4.  **Detalle de Producto**
    * Los usuarios podrá ver de cada producto sus características, precios, colores, disponibilidad... .
    

5.  **Gestión de Perfil**
    * Los usuarios podrán modificar sus datos personales, por ejemplo: dirección, número de teléfono... .
   

6.  **Gestión de Pedidos**
    * Los administradores podrán hacer un seguimiento del pedido, preparado, enviado y entregado.
